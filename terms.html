2. Description of Service & Local Processing Architecture

SAVY is a free, privacy-first web application providing client-side PDF document manipulation tools including viewing, annotating, merging, splitting, compressing, converting, and redacting.

Unlike conventional cloud PDF tools, SAVY does not transmit your document contents to remote servers for processing. All operations execute inside your client browser environment using WebAssembly, HTML5 Canvas, and client-side JavaScript engines.
