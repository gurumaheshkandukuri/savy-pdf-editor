SAVY Privacy & Security Center

Guaranteed Principle

Your PDF is processed locally in your browser and is not uploaded to SAVY's servers.

SAVY runs entirely client-side inside your browser sandbox. Unlike traditional online PDF tools that upload documents to remote cloud queues, your files, annotations, drawings, and signatures are held in volatile browser RAM.

⚡ Zero Document Uploads

All parsing, page operations, annotations, and PDF exports are compiled in WebAssembly and JavaScript in your browser memory.

🔒 Zero Cloud Storage

SAVY has no Amazon S3, Google Cloud Storage, or Azure Blob buckets. Documents cease to exist in memory the moment you close the tab.

🛡️ Zero Backend Processing

There are no Python, Node.js, or Go backend processing servers. All computation executes locally on your CPU/GPU hardware.

🚫 Zero Tracking / Telemetry

No Google Analytics, Meta Pixel, Mixpanel, or PostHog tracking scripts. We do not track document contents or user behavior.

1
Local File Ingestion

When you select or drop a PDF, the file bytes are read via the standard HTML5 FileReader API directly into an ArrayBuffer in volatile browser memory.

2
Browser Sandbox Manipulation

All page modifications, annotations, signatures, and stamps are rendered to in-memory HTML5 canvases and compiled via pure JavaScript (pdf-lib).

3
Direct Local Download

The compiled PDF is instantiated as a local browser Blob and triggered via a transient blob: Object URL. The Object URL is tracked and explicitly revoked after download.

4
Instant Session Purge

Clicking "Close Document" or navigating away instantly purges all ArrayBuffers, canvas contexts, annotation models, and Object URLs from memory.

Accurate Network Transparency

SAVY does not claim "zero network requests" globally because third-party JavaScript libraries are loaded via CDN upon initial page load:

  • Mozilla PDF.js (v3.11.174): Loaded from Cloudflare CDN (cdnjs.cloudflare.com) to render PDF pages locally.
  • pdf-lib (v1.17.1): Loaded from Cloudflare CDN (cdnjs.cloudflare.com) for client-side PDF document manipulation.
Critical Privacy Distinction: CDN requests are purely static GET requests for JavaScript libraries. No document data, filenames, image contents, signatures, or user inputs are EVER included in any network request.

SAVY's AI intelligence features operate 100% on your local device. We never silently transmit PDF text, document contents, or questions to external cloud AI APIs or paid backend endpoints.

When supported by modern browsers (e.g., Chrome Built-in AI via window.ai or WebGPU), models run purely on local device silicon with zero network transmission.

🚫 Zero Hallucinations Guarantee

PDF Password Protection & Encryption

Engine Notice:

True PDF encryption requires an additional compatible client-side PDF encryption implementation.

PDF password protection is governed by the ISO 32000 specification and requires writing encrypted binary objects using standard cryptographic handlers (AES-128, AES-256, or RC4).

The client-side PDF manipulation engine (pdf-lib) does not natively support writing encrypted PDF structures.

SAVY Commitment to Honesty: SAVY strictly refuses to simulate password protection with insecure client-side wrappers or pseudo-locks. We only provide genuine, verifiable security features.
